# Публикация отдельного архива

Предлагаемое имя: `dota2-tech-flood-archive-2019-2022`.

Описание для GitHub:

> Архивная история «Технической флудильни» Dota2.ru за 2019–2022 годы: 25 участников, история треда и выборочные технические проверки.

Этот репозиторий отдельный от [dota2-tech-flood-study](https://github.com/HFUBlackRabbit/dota2-tech-flood-study). В нём нет полной выгрузки сообщений форума и исходной базы.

Перед публикацией выполните в корне репозитория:

```bash
python3 scripts/validate.py
git status --short --branch
```

Создайте на GitHub новый пустой репозиторий с выбранной видимостью. Не добавляйте в нём автоматически README или другие начальные файлы. Затем привяжите адрес нового репозитория и загрузите ветку `main`:

```bash
git remote add origin "REPOSITORY_URL"
git push -u origin main
```

Вместо `REPOSITORY_URL` используйте адрес созданного репозитория. В названии и README слово «архив» обозначает исторический тред; GitHub-функция Archive отдельно не включается и переводит репозиторий в режим только для чтения.
