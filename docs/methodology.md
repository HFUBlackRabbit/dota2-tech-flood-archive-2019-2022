# Методология и границы

Исследование относится к публичному снимку треда № 1300377 за 11.08.2019–19.02.2022 UTC. В исходном архиве — 33 410 уникальных `post_id`, 294 уникальных `author_id` и 1 344 страницы; выгрузка сделана 1 ноября 2026 года. Граница снимка — `post_id` 26619911. Снимок не атомарен: сообщения могли быть изменены во время выгрузки; удалённые и недоступные сообщения не восстановлены.

Авторы отобраны по группировке `author_id` и числу уникальных `post_id` не менее 100; таких авторов 25. Уникальный ID поста, а не видимый номер на странице, использован как единица учёта. В исходной нумерации есть пропуски и повторы; уникальные посты при этом не объединялись. Имена в README — отображаемые имена снимка, а не исчерпывающая история переименований. О разных аккаунтах, которые один участник называл своими, сказано в [истории треда](../thread.md).

Отдельный AI-воркер прочитал сообщения каждого из 25 авторов; остальные 2 890 сообщений распределялись между воркерами по хронологическим блокам. Для важных эпизодов дополнительно рассматривались соседние ответы. Данные о прочитанных post_id и проверках представлены в [coverage.json](../coverage.json). Для двух авторов потребовались отдельные повторные проходы, чтобы восстановить последовательность чтения; их журналы сверялись с порядком SQLite.

В рассказах авторский текст отделялся от цитат собеседников. Слова о собственных покупках, диагнозах и результатах тестов передаются как сообщения участников, а не независимое установление факта. Неизвестный исход, внутренняя шутка и предположение отдельно обозначены в тексте.

Для выбранных существенных технических утверждений использовались внешние спецификации, документация и тесты с учётом моделей и условий. Проверка выборочная: записи JSONL — реестр разобранных примеров, а не исчерпывающая оценка всех технических сообщений. Некоторые записи маркируют недостаток данных и не имеют независимого источника, способного установить личный результат.

Источники в полном виде, SQLite, HTML страниц, внешние изображения и рабочие журналы отдельных воркеров в этом репозитории не опубликованы. Поля `read_log` и `journal` в coverage.json — ссылки на рабочие материалы первоначального исследования, которых в репозитории нет; непосредственно прочитанные ID сохранены внутри coverage.json. `source-verification.json` описывает прежнюю проверку исходного архива, а `scripts/validate.py` проверяет только файлы этого комплекта. Содержательное чтение и оценку фактов одной программной проверкой воспроизвести нельзя.
